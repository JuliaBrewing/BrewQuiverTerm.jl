Views

Each view of the app is drawn by a rendering function, which takes a session of BrewQuiverUICore and returns a Term renderable: they can be used on their own, in the REPL or in a notebook, and printed in color.

The overview

render_overview: a panel for the ingredients (the nodes in no vessel) and one for each vessel, in topological order, with the results of each node and the arrows leaving it.

A node, an arrow

The drawing

render_dag draws the quiver as a layered graph, from the positions of BrewQuiverUICore: a column per layer, the arrows to the next layer along the row of their source, longer ones along the empty rows between, so that they never pass behind a node.

The inventory

render_inventory: what the brew needs of each ingredient, with the stock of the library of the session (here, one with a part of the malt and plenty of hops):

lib = Library()
push!(lib, pale; stock = 3u"kg")
push!(lib, cascade; stock = 100u"g")
set_library!(s, lib)
text(render_inventory(s; width = 90))
