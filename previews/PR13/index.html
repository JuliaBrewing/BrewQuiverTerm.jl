BrewQuiverTerm.jl

A terminal user interface for BrewQuiver.jl, the engine that models brewing as a quiver: a directed acyclic multigraph whose nodes are the contents of vessels at the stages of the brewing, and whose arrows are the processes between them. It is built with Term.jl on BrewQuiverUICore.jl, the core it shares with the graphical interface.

With it you can open a quiver or import a BeerJSON recipe, or start from nothing, and

  • see every node with its results (volume, gravity, ABV, IBU, color, temperature, mash pH), grouped by vessel, and each node or arrow in detail;
  • build and edit the quiver: lots of ingredients (defining new ones as you go), water and its profile, stages, arrows, equipment;
  • undo and redo every edit, with a history;
  • draw the quiver as a graph, see the timeline of the vessels, and solve for targets;
  • save, with a question before losing changes.

Installation and start

The package is under development and not registered. It takes BrewQuiver, its siblings and BrewQuiverUICore from GitHub through the [sources] of its Project.toml (Julia 1.11 or later):

using Pkg
Pkg.add(url = "https://github.com/JuliaBrewing/BrewQuiverTerm.jl")

using BrewQuiverTerm
BrewQuiverTerm.run("bitter.quiver.json")       # a quiver
BrewQuiverTerm.run("recipe.json")              # a BeerJSON recipe, imported
BrewQuiverTerm.run(; library = "my_ingredients.json")   # a new quiver, with a library

Press ? for the keys, q to quit.
